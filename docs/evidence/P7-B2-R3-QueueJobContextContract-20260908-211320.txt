===== 4. SEMANTICA DE UNKNOWN =====
UNKNOWN significa:
- evidencia insuficiente
- propiedad ausente
- dato no interpretable de forma segura

UNKNOWN NO significa:
- error del programa
- estado fallido
- autorizacion para recovery
- autorizacion para borrar el job

===== 5. REGLAS DE NORMALIZACION V1 =====
Origin:
  SubmittedTime < ObservationStartedAt -> PREEXISTING
  SubmittedTime >= ObservationStartedAt -> NEW
  SubmittedTime null -> UNKNOWN

Age:
  <= 2 min  -> FRESH
  >2 <=15   -> AGING
  >15       -> STALE
  no SubmittedTime -> UNKNOWN

NOTA: thresholds son de contrato v1 provisional.
B3 puede externalizarlos a policy/config.

Health:
  Flag Error true -> ERROR
  JobStatus conocido sin Error -> NORMAL
  JobStatus ausente/vacio -> UNKNOWN

Progress:
  TotalPages null/<=0 -> UNKNOWN
  PagesPrinted null -> UNKNOWN
  PagesPrinted <=0 -> NO_PROGRESS
  0 < PagesPrinted < TotalPages -> PARTIAL_PROGRESS
  PagesPrinted >= TotalPages -> COMPLETE

===== 6. PRECEDENCIA SUMMARYCLASSIFICATION =====
Orden de precedencia V1:
1. Flags.Deleting -> TRANSITIONING
2. Flags.Paused -> PAUSED
3. Health=ERROR + Age=STALE + Progress=NO_PROGRESS -> STALLED_ERROR
4. Health=ERROR -> ERROR_ACTIVE
5. Progress=PARTIAL_PROGRESS -> PROGRESSING
6. Flags.Printing + Progress=NO_PROGRESS -> PRINTING_UNCONFIRMED
7. Age=STALE + Progress=NO_PROGRESS -> STALLED_NO_ERROR
8. Progress=COMPLETE -> COMPLETE
9. otherwise -> ACTIVE_OR_QUEUED

SummaryClassification NO debe derivar policy directamente.
